# 原生 PDF 阅读器增强计划

目标：围绕 Obsidian 原生 PDF 阅读器补齐"论文阅读"所需的能力。不改造阅读器本身，只做旁挂式功能（覆盖层、弹层、设置项）。

工作分支：main 上小步提交（每项一个 commit）。

## 实施原则

- 每完成一项更新本文档状态并附实现说明。
- UI 改动需在 Obsidian 中人工验证。
- 不触碰原生阅读器核心视图结构；新功能以覆盖层/弹层/工具栏形式叠加。
- 写回 PDF 时注意触发原生视图重载（见已实现的 `pdfAnnotationWriteback` 设置）。
